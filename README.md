# 📊 Sistema de Análise de Desempenho Escolar

Sistema via console desenvolvido em Java para analisar o desempenho de uma turma escolar.

## 📌 Funcionalidades

- Cadastro de alunos com nome e nota
- Validação de notas (0 a 10)
- Cálculo da média da turma
- Identificação do(s) aluno(s) com maior nota (com tratamento de empate)
- Identificação do(s) aluno(s) com menor nota (com tratamento de empate)
- Listagem de alunos aprovados e reprovados

## 🛠️ Tecnologias

- Java 21
- Arrays paralelos
- Métodos estáticos modulares
- Scanner para entrada de dados

## 📚 Contexto

Projeto desenvolvido no 2º bimestre do curso de Ciências da Computação com foco em lógica de programação, modularização e boas práticas com arrays.

## ▶️ Como executar

1. Clone o repositório
2. Compile: `javac Main.java`
3. Execute: `java SistemaEscolar.Main`
